# The One-Effect Rule: Singularity of Action & Causality

## 1. Concept: "One Effect" != "One Element"
The rule does not limit the number of moving parts; it limits the number of **unrelated actions competing for the viewer's attention**.

### Example of Valid Complexity (The Elevator Mechanism):
- When an elevator ascends, the hand-crank rotates $\rightarrow$ the gears turn $\rightarrow$ the steel cable tightens $\rightarrow$ the lift cage rises.
- **Verdict**: This is **ONE EFFECT** (the ascent of the lift). All 4 elements are mechanically and causally linked. The viewer perceives one coherent story.

### Example of Visual Chaos (Prohibited):
- A lift ascends + sparks fly randomly in the corner + astral rings spin in the background + text jerks + bloom flashes.
- **Verdict**: 5 unrelated visual shows fighting each other. The brain perceives cheap noise.

---

## 2. The Verification Question
For every moving element on screen, ask:
> **"Does this element serve the current narrative action, or is it living a separate life?"**

| Element | Serves the Action? | Decision |
|---|---|---|
| Shards spiraling into letterforms | Yes — main action | ✅ Keep |
| Staggered delay & velocity curl | Yes — mechanical consequence of flight | ✅ Keep |
| Ink-soaking glow upon landing | Yes — completion of the incantation | ✅ Keep |
| Dust motes drifting in window beam | Yes — static ambient context | ✅ Keep |
| Gold rings/spirals spinning alone | No — disconnected decoration | ❌ REMOVE |

---

## 3. Application to deusflowph
At any given moment, there is **one primary narrative action**: parchment/ink shards morphing into a target form (headline, photo, or 3D camera). All other motion is either:
1. The physical mechanism of that morph (curl noise, velocity dispersal, landing pulse), OR
2. Subdued static atmosphere (drifting dust motes in the window beam, breathing candlelight bokeh).
